Abstract

What is SPRINT?

An intelligent IoT solution bridging the gap between traditional farming and modern automation

SPRINT is an affordable, cloud-connected smart spraying system designed to automate the distribution of water, pesticides, and liquid fertilizers in farms and gardens. Built using an ESP-01 Wi-Fi microcontroller, a relay, voltage regulators, a 12V pressure pump, and solenoid valves — all orchestrated from a central liquid source.

Instead of old-school timers with blind schedules, SPRINT pairs with a custom Android mobile app that lets the user activate the spray, choose the liquid type, and monitor the system in real-time — anywhere, anytime. The Firebase Realtime Database serves as the cloud backbone, eliminating fixed schedules and adapting to field needs dynamically.

The modular architecture is designed for future expansion: soil moisture sensors and weather APIs can be integrated to prevent over-spraying or spraying during rain — making it equally suitable for terrace gardens and open agricultural fields.

Working Principle

How SPRINT Works

Six elegant steps from user intent to precision spraying

01
📱

User Command

The user initiates spraying via the mobile app — tapping "Start Spraying" or selecting a liquid type (water / pesticide / fertilizer).

02
☁️

Firebase Update

The app writes a specific key-value pair to the Firebase Realtime Database. The cloud acts as the message broker between phone and hardware.

03
📡

ESP-01 Data Polling

The ESP-01 continuously monitors Firebase, fetching new values in real-time over Wi-Fi. No polling delay — it reacts as soon as the database changes.

04
🧠

Logical Decision

The microcontroller evaluates the received value and decides whether to activate its GPIO pin — translating cloud commands to hardware signals.

05
⚙️

Relay Activation

The relay module energises the 12V pressure pump and the 24V solenoid valve simultaneously, opening the liquid flow path.

06
💧

Spraying Process

The system sprays the field until a "stop" command is sent via the app or a programmed timeout occurs — no manual intervention needed.

Hardware

Key Components

Carefully selected for reliability, cost-effectiveness, and agricultural suitability

ESP-01 (ESP8266)

Core Control Unit · WiFi MCU

Ultra-compact Wi-Fi microcontroller chosen after testing ESP-32, NodeMCU, Raspberry Pi 3B+, and H5 Stack. Best balance of size, power consumption, and Firebase compatibility.

3.3V · 2 GPIO pins · IEEE 802.11 b/g/n

Relay Module

Switch · Power Controller

Single-channel ESP-01 compatible relay that safely switches high-voltage pump and solenoid circuits from the low-power 3.3V GPIO output of the microcontroller.

Single-channel · ESP-01 compatible · 10A rating

Pressure Pump

12V DC · Water Pressurisation

Mini diaphragm pump providing the pressure needed to deliver liquid through the spray nozzle system. Controlled via the relay for clean on/off switching.

12V DC · Mini diaphragm · Relay-controlled

Solenoid Valve

24V DC · Liquid Flow Control

Electromagnetic valve that opens and closes the liquid pathway on command. Requires 24V, supplied by the MT3608 boost converter from the 12V main line.

24V DC · Normally closed · 1/2" inlet

LM2596 Buck Converter

Step-Down · 12V → 3.3V

Steps the 12V main supply down to the stable 3.3V required by the ESP-01. Critical for preventing the microcontroller from voltage spikes that caused earlier component failures.

Input: 12V · Output: 3.3V · Efficient step-down

MT3608 Boost Converter

Step-Up · 12V → 24V

Boosts the 12V supply to the 24V needed to actuate the solenoid valve. Separate power lines ensure stable delivery to both the ESP and the high-voltage actuation components.

Input: 12V · Output: 24V · Isolated power path

Software

Technology Stack

Open-source tools chosen for rapid prototyping, low cost, and robust Firebase integration

IoT Firmware
Arduino IDE C++ firmware development for ESP-01. Manages Firebase Client library integration and Serial monitoring.
Firebase ESP Client Connects ESP-01 to Firebase RTDB. Handles authentication, read/write, and real-time streaming.
WiFiManager Captive-portal Wi-Fi setup. Lets the device join new networks without re-flashing firmware.
ArduinoJson Fast, memory-efficient JSON parsing for cloud data structures. Critical on ESP-01's 96KB RAM.
Mobile App
Android Studio Full Android app development. Provides a user-friendly UI with connectivity status, liquid selection, and real-time feedback.
Firebase Android SDK Reads and writes to Firebase RTDB from the phone. Provides authentication and real-time listeners.
ConstraintLayout UI Responsive Android UI layout system. Renders control buttons and status indicators cleanly.
Cloud Backend
Firebase RTDB Serverless real-time database. JSON tree structure stores device commands hierarchically. Free Spark plan used.
Firebase Authentication Secures device-to-cloud and app-to-cloud communication with token-based auth.
ESP8266WebServer Local LAN status page for offline diagnostics — displays system state without Firebase connectivity.
Web Showcase
Node.js + Express Lightweight server to host this project showcase. Serves static assets and exposes a project metadata API.
Vanilla Angular-style SPA Modular, component-driven JavaScript with scroll-triggered animations and a responsive layout system.
Vercel Deployment Serverless Node.js hosting with automatic HTTPS, CDN, and zero-config deployments from GitHub.

Limitations

Challenges & Honest Trade-offs

Every engineering solution involves trade-offs — here's what SPRINT acknowledges

📶

Wi-Fi in Rural Fields

Stable internet access in remote agricultural fields can be unreliable. SPRINT requires connectivity for Firebase communication — an offline fallback is not yet implemented.

Planned fix: Bluetooth / physical pushbuttons as fallback
💾

Limited GPIO Pins

ESP-01 has only 2 usable GPIO pins, making multi-sensor integration difficult. Adding soil moisture or humidity sensors would require migrating to ESP-32.

Planned fix: Upgrade to ESP-32 for v2.0
⚡

Power Stability

Multiple components with different voltage requirements led to early component failures during testing. The final LM2596 + MT3608 combo resolved this with separate isolated power lines.

Status: Resolved in final prototype
🌐

Cloud Dependency

Entire operation relies on internet availability. During a connectivity outage, the system is inoperative. No local control mode exists in the current version.

Planned fix: Local LAN fallback via ESP WebServer
Roadmap

Future Scope & Enhancements

SPRINT v1 is the foundation — here's where it goes next

01
🌡️

Sensor Integration

Adding soil moisture, temperature, and humidity sensors for automatic, condition-based spraying — the system decides when crops actually need water, not a fixed timer.

02
🌦️

Weather API Integration

Connecting to OpenWeatherMap API to prevent spraying during rainfall or adverse conditions. During testing, the system once sprayed right before rain — this fix eliminates that waste.

03
☀️

Solar Power

Incorporating solar panels for off-grid operation. ESP-01's minimal idle power draw makes it ideal for solar + battery pack configurations in remote fields.

04
📵

Offline Local Control

Fallback to Bluetooth or physical pushbuttons for control during internet outages — enhancing system resilience for areas with unreliable connectivity.

05
📊

Mobile App Enhancement

Upgrading the app with graphical dashboards, voice commands, multi-zone control, and scheduled spraying features. Current UI is functional but minimal.

06
🔗

Multi-Inlet Plumbing

Redesigning for multiple pipe inlets with individual solenoid valves per zone — significantly increasing practical value for larger farm setups.
